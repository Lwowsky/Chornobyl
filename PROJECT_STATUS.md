## v0.74 — Daily Room Supply
- Додано нову механіку `Щоденний запас` для викупленої кімнати відпочинку.
- Нагороду можна забрати 1 раз на 24 години; таймер зберігається через `localStorage`, тому перезавантаження сторінки не скидає cooldown.
- Розмір нагороди росте разом із рівнем кімнати: 1 рівень починається з ₴25 + бинт, далі ростуть гроші та кількість припасів.
- На рівнях 1–4 нагорода фіксована відповідно до рівня кімнати.
- З 5 рівня відкривається вибір одного з трьох типів щоденного запасу: `Медичний`, `Технічний`, `Торговий`.
- Медичний запас дає бинти/йод/аптечки, технічний — матеріали/набої/рідкісні матеріали, торговий — підвищену грошову нагороду.
- На 10 рівні до щоденного запасу додається `Елітний ящик`.
- Додано блок щоденного запасу для desktop sidebar та adaptive/mobile info-cards без зміни таблиці `Усі рівні`.
- Після отримання нагороди показується точний список виданих ресурсів і countdown до наступного збору.
- Негрошові ресурси зберігаються у внутрішньому сховищі кімнати та доступні через `GameRestRoom.getStorage()` для подальшого підключення до інвентарю.
- Стан кімнати, обраний тип запасу та ресурси кімнати тепер зберігаються у `localStorage`.
- Перевірено: дубльованих HTML id немає, `!important` немає, `rest-room.js` проходить syntax check.
