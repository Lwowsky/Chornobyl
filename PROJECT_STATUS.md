## Зафіксовані правила

- Основний інтерфейс: верхній HUD + центральний контент + нижня навігація.
- Профіль не має кнопки в нижньому меню; відкривається натисканням на аватар у верхньому HUD.
- Профіль має одну й ту саму композицію на Desktop / Tablet / Mobile. На менших екранах вона стискається, але не перебудовується в інший дизайн.
- Базовий profile dialog: фіксований `520×760 px`. На менших viewport масштабується тільки весь dialog одним коефіцієнтом; внутрішня геометрія не перебудовується.
- Фон гри за профілем сильно розмивається та затемнюється.
- Блок `нік / рівень / бойова міць` усередині профілю прибраний: ця інформація вже є у верхньому HUD.
- Герой завжди по центру.
- Ліворуч від героя 5 слотів: Голова / Маска / Тіло / Плащ / Рукавиці.
- Праворуч 5 слотів: Штани / Взуття / Талісман / Артефакт / Дозиметр.
- Рюкзак як слот профілю не використовуємо.
- Ближню та дальню зброю прибрано з бокових колонок.
- Усередині нижньої частини фото героя розташовано 3 бойові слоти: `Ближня зброя / Дальня зброя / Набої`.
- Слоти ближньої та дальньої зброї мають той самий розмір, що й основні слоти екіпіровки; слот набоїв навмисно менший.
- Набої в майбутньому матимуть тип/рідкість і можуть давати бонуси, наприклад до атаки та криту. Механіку поки не підключаємо.
- Унизу профілю залишається компактне `Зведення характеристик` у дві колонки.
- Майбутній герой/екіпіровка використовують одну координатну систему. Робоче полотно: `768×1024`, master-render: `1536×2048`.
- Майбутня сітка героя: `96×128`.
- Не використовувати `!important`.
- `css/styles.css` — тільки глобальні стилі/reset.
- Кольори, шрифти, розміри та design tokens — у `css/core/variables.css`.
- Responsive CSS — окремо mobile / mobile-small / tablet / desktop.
- UI-тексти готувати через i18n; зараз активна тільки українська.

## v0.07 — Uniform Profile Scaling Fix
- Виправлено головну проблему mobile/responsive профілю: фіксований дизайн `520×760` більше не намагається жити у viewport як нескейлений 520px layout.
- Додано `profile-stage`, який займає вже фактичний візуальний розмір масштабованого профілю. Сам `profile-dialog` залишається логічно рівно `520×760` і масштабується лише цілком.
- Масштаб тепер обчислюється одним коефіцієнтом: `min(1, доступна ширина / 520, доступна висота / 760)`. Ширина і висота ніколи не змінюються незалежно одна від одної.
- На великих/середніх екранах, де `520×760` влазить, профіль завжди має однаковий розмір. На меншому екрані весь профіль пропорційно зменшується так, щоб повністю влазити і по ширині, і по висоті без внутрішнього scroll.
- Для мобільних браузерів використовується `visualViewport`, тому масштаб враховує реальну видиму висоту після browser UI / DevTools viewport.
- Прибрано попередній мінімальний clamp `0.5`, який міг залишати профіль більшим за дуже вузький viewport.
- Responsive CSS як і раніше не містить окремої геометрії профілю.
- Структура слотів, hero-frame та нижнє зведення характеристик не перебудовувалися.

### Зафіксоване responsive-правило
Профіль — це фіксований canvas `520×760`. Не змінювати окремо його width/height через media queries. Якщо він не влазить — масштабувати весь canvas одним коефіцієнтом через `profile-stage`. Внутрішній scroll для вкладки Герой не використовувати.
